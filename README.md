# 🌈 心晴小星球 · 小三正向思維 × 靜心網站

為小學三年級（約 8–9 歲）學生而設的互動網站，用遊戲化方式練習 **正向思維（Positive Thinking）** 與 **靜心（Mindfulness）**。純靜態網站，無需後端，可直接用 GitHub Pages 發佈。

## 功能

| 單元 | 內容 | 學習目標 |
| --- | --- | --- |
| 🏠 首頁 | 活動地圖、每日金句 | 建立使用動機 |
| 🌈 彩虹呼吸 | 4-2-6 呼吸動畫（吸氣／停／呼氣），語音導航，5 個循環得星星 | 呼吸覺察、放鬆 |
| 🧘 身體掃描 | 7 步引導（頭→肩→手→腹→腳），可自動播放 | 身體覺察、專注當下 |
| 🎯 專注遊戲 | 靜心泡泡（30 秒反應遊戲）、記憶花園（6 對配對卡） | 選擇性注意力、工作記憶 |
| 💛 感恩日記 | 心情選擇 + 3 件好事，localStorage 保存，連續記錄天數 | 感恩練習、正向情緒 |
| 🌱 正向想法 | 10 張「卡住的想法 → 換個講法」翻卡，一分鐘急救呼吸 | 成長型思維、認知重構 |
| 🎬 影片區 | 12 段廣東話／英文正向教育與靜心影片（YouTube 嵌入） | 示範與延伸學習 |
| 🏅 我的成就 | 8 個徽章、星星統計、重設紀錄 | 正向回饋、習慣養成 |

## 設計取向

- **遊戲化**：星星、徽章、動畫、音效（Web Audio 即時合成，毋須音檔）。
- **語音導航**：使用瀏覽器 Web Speech API（優先 `zh-HK` 粵語），可一鍵關閉。
- **無障礙**：大字級、52px 觸控目標、`aria-*` 標籤、支援 `prefers-reduced-motion`。
- **私隱**：所有進度只存在學生裝置的 `localStorage`，不上傳、不收集任何個人資料。
- **零依賴**：沒有框架、沒有建置步驟，`index.html` 直接開啟即可。

## 本機預覽

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 檔案結構

```
index.html          單頁應用（8 個 view）
assets/style.css    樣式與響應式版面
assets/app.js       呼吸引擎、遊戲、日記、徽章、語音
```

## 給老師／家長的建議

1. 每次使用 5–10 分鐘，一天 1–2 個練習即可。
2. 做完練習後，花 1 分鐘問學生：「你身體有咩感覺？」「心情有冇唔同？」。
3. 感恩日記可配合課堂「分享一件好事」環節。
4. 網站內容屬教學與放鬆用途，不能代替專業心理輔導。
